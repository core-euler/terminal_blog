Цвета здесь не задаются хексами: у каждого есть имя, а конкретный оттенок берётся из текущей темы. Переключите тему в строке статуса, и весь пост перекрасится вместе с ней.

## Цвет в тексте

Запись `:имя[текст]` красит кусок абзаца. Доступны :red[red], :orange[orange], :yellow[yellow], :green[green], :cyan[cyan], :blue[blue], :purple[purple], :pink[pink] и :dim[dim] для приглушённого текста.

Внутри можно использовать обычную разметку: :green[**жирный** и `код`]. Если нужен HTML, работает и `<span class="c-red">`.

Длинные абзацы лучше оставлять основным цветом: пастельный текст на тёмном фоне быстро утомляет.

## ASCII-арт

Арт пишется в блоке кода с языком `ascii`. Внутри работает та же запись цвета, а `]` экранируется как `\]`.

```ascii alt="Кот сидит на ковре"
   /\_/\
  ( :yellow[o].:yellow[o] )   :dim[мяу]
   > :pink[^] <
  :purple[~~~~~~~~~~~]
```

## Анимация

Слово после `ascii` включает эффект: `wave` пускает по символам градиент из цветов темы, `pulse` плавно гасит и зажигает, `blink` мигает.

```ascii wave alt="Надпись hello"
 _          _ _
| |__   ___| | | ___
| '_ \ / _ \ | |/ _ \
| | | |  __/ | | (_) |
|_| |_|\___|_|_|\___/
```

Строка `%%` делит арт на кадры, `fps=` задаёт скорость. Анимация сделана на чистом CSS, а при включённом в системе «уменьшении движения» останавливается на первом кадре.

```ascii fps=4 alt="Кот моргает"
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :dim[-].:dim[-] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
```

```ascii fps=8 alt="Индикатор загрузки"
[:green[=]     ] :dim[загрузка]
%%
[:green[==]    ] :dim[загрузка]
%%
[:green[===]   ] :dim[загрузка]
%%
[:green[====]  ] :dim[загрузка]
%%
[:green[=====] ] :dim[загрузка]
%%
[:green[======]] :dim[готово]
```
