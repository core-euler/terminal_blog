Цвета задаются не хексами, а именами: конкретный оттенок берётся из текущей темы. Переключите тему в строке статуса — и весь пост перекрасится вместе с ней.

## Цвет в тексте

Запись `:имя[текст]` красит кусок строки. Доступны девять имён:

- :red[red] — `:red[текст]`
- :orange[orange] — `:orange[текст]`
- :yellow[yellow] — `:yellow[текст]`
- :green[green] — `:green[текст]`
- :cyan[cyan] — `:cyan[текст]`
- :blue[blue] — `:blue[текст]`
- :purple[purple] — `:purple[текст]`
- :pink[pink] — `:pink[текст]`
- :dim[dim] — `:dim[текст]`, приглушённый текст

Внутри работает обычная разметка: :green[**жирный** и `код`]. Вместо короткой записи можно писать HTML: `<span class="c-red">текст</span>`.

Что не станет цветом: время `10:30`, `config:prod` и любое неизвестное имя вроде `:foo[текст]` — такой текст остаётся как есть. Внутри цветного куска `]` пишется как `\]`, а обратный слэш — как `\\`. Вне цветных кусков оба символа пишутся как обычно, поэтому `/\_/\` трогать не нужно.

Цвет стоит беречь для акцентов: длинный абзац пастельным цветом на тёмном фоне читать тяжело, поэтому основной текст всегда цвета `text`.

## Блок ASCII

Арт пишется в блоке кода с языком `ascii`. Пробелы сохраняются, шрифт моноширинный, внутри работает та же запись цвета:

````md
```ascii alt="Кот"
   /\_/\
  ( :yellow[o].:yellow[o] )   :dim[мяу]
   > :pink[^] <
  :purple[~~~~~~~~~~~]
```
````

Результат:

```ascii alt="Кот"
   /\_/\
  ( :yellow[o].:yellow[o] )   :dim[мяу]
   > :pink[^] <
  :purple[~~~~~~~~~~~]
```

- `alt="…"` — описание для скринридеров. Без него арт для них скрыт, как декоративный.
- Внутри блока работает только запись цвета: markdown, ссылки и подсветка кода не разбираются.
- Весь блок получает в гаттере один номер строки, а не по строке на каждую строку арта.

## Эффекты

Слово после `ascii` включает анимацию: `wave` пускает по символам градиент из цветов темы, `pulse` плавно гасит и зажигает арт, `blink` мигает им, как курсором.

```ascii wave alt="Надпись hello"
 _          _ _
| |__   ___| | | ___
| '_ \ / _ \ | |/ _ \
| | | |  __/ | | (_) |
|_| |_|\___|_|_|\___/
```

```ascii pulse alt="Рамка с подсказкой"
+-------------------+
| :cyan[нажмите F1] |
+-------------------+
```

```ascii blink alt="Индикатор записи"
:red[●] запись
```

## Кадры и скорость

Строка `%%` делит арт на кадры, `fps=N` задаёт скорость — от 1 до 30, по умолчанию 6. Кадры могут быть разной высоты: короткие дополняются пустыми строками, чтобы блок не дёргался.

````md
```ascii fps=4 alt="Кот моргает"
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :dim[-].:dim[-] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
```
````

```ascii fps=4 alt="Кот моргает"
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
%%
   /\_/\
  ( :dim[-].:dim[-] )
   > :pink[^] <
%%
   /\_/\
  ( :yellow[o].:yellow[o] )
   > :pink[^] <
```

Спиннер — четыре кадра по одному символу:

```ascii fps=8 alt="Спиннер"
:cyan[|] загрузка
%%
:cyan[/] загрузка
%%
:cyan[-] загрузка
%%
:cyan[\\] загрузка
```

Полоса загрузки — шесть кадров разной длины:

```ascii fps=8 alt="Полоса загрузки"
[:green[=]     ] :dim[загрузка]
%%
[:green[==]    ] :dim[загрузка]
%%
[:green[===]   ] :dim[загрузка]
%%
[:green[====]  ] :dim[загрузка]
%%
[:green[=====] ] :dim[загрузка]
%%
[:green[======]] :dim[готово]
```

## Экранирование

Внутри цветного куска два символа имеют особый смысл: `]` закрывает запись, `\` экранирует следующий символ. Поэтому скобка внутри цвета пишется как `\]`, а сам слэш — как `\\`:

```ascii alt="Экранирование"
массив :cyan[arr\]i]
путь   :yellow[C:\\tmp]
```

Вне цветных кусков экранировать нечего: в `/\_/\`, `[ok]` и `100%` слэши и скобки остаются собой.

## Ширина

На телефоне помещается примерно 40–45 символов в ширину. Всё, что шире, прокручивается по горизонтали — страница при этом не разъезжается:

```ascii alt="Широкая строка"
:green[да] :yellow[нет] :cyan[может быть] :purple[не знаю] :red[спросите завтра]
```

Практический предел для арта, который должен быть виден целиком, — около 40 символов.

## Галерея

Два готовых арта: сердце живёт эффектом, тарелка — кадрами. Копировать можно целиком.

Сердце дышит: `pulse` гасит и зажигает весь блок, поэтому кадры ему не нужны.

```ascii pulse alt="Сердце"
   :pink[***]   :pink[***]   
  :pink[*****] :pink[*****]  
 :pink[*************] 
 :red[#############] 
  :red[###########]  
   :red[#########]   
    :red[#######]    
     :red[#####]     
      :red[###]      
       :red[#]       
```

У тарелки три кадра, `fps=3`: она едет вправо, а звёзды стоят на месте — так движение читается без перерисовки фона.

```ascii fps=3 alt="Летающая тарелка"
   :cyan[.---.]   :dim[*]                      
  ( :yellow[o] :yellow[o] )                        :dim[*]
 :dim[=========]                        
      :dim[*]             :dim[*]             
  :dim[*]                         :dim[*]     
%%
           :dim[*]  :cyan[.---.]               
             ( :yellow[o] :yellow[o] )             :dim[*]
            :dim[=========]             
      :dim[*]             :dim[*]             
  :dim[*]                         :dim[*]     
%%
           :dim[*]             :cyan[.---.]    
                        ( :yellow[o] :yellow[o] )  :dim[*]
                       :dim[=========]  
      :dim[*]             :dim[*]             
  :dim[*]                         :dim[*]     
```

## Уменьшение движения

Анимации сделаны на чистом CSS, без JavaScript. Если в системе включено «уменьшение движения», все эффекты останавливаются, а у покадровой анимации остаётся первый кадр — арт при этом читается как обычная картинка.
