Клиент хочет видеть свои залоги, оценки и отделения в телефоне, а данные живут в 1С «Бухгалтерия ювелирного ломбарда». Между ними — прослойка на FastAPI: приложение на Flutter разговаривает только с ней.

Основная работа оказалась не в коде, а в наведении порядка. Проект существовал в трёх расходящихся линиях — монорепозиторий, отдельный репозиторий бэкенда и рабочая копия на сервере. Я свёл их в одну ветку, собрал архив для передачи и развернул всё на VPS заказчика: Docker, Caddy с сертификатом, API отвечает по HTTPS.

Остался один внешний блокер — белый список IP на стороне 1С. Приложение доходит до экрана входа и останавливается, пока адрес сервера не разрешат в конфигурации.

Отдельной веткой — перенос бэкенда с Python на ASP.NET Core: около 1850 строк C# против 4800 строк Python, совместимость проверена прогоном обеих версий на одной последовательности запросов к тестовой 1С.
